# Vendored Wispral Contract Schemas (One-Way `Apache-2.0 -> AGPL-3.0-only`)

The JSON Schema files in this directory are vendored **one-way** from
`TheHalfMoon/Wispral` (`docs/engineering/contracts/*.schema.json`, licensed
under `Apache-2.0`) into `TheHalfMoon/wisprstudio` (`AGPL-3.0-only`):

- `consent_record.schema.json`
- `export_provenance.schema.json`
- `model_manifest.schema.json`
- `network_manifest.schema.json`

 License isolation rule: `Apache-2.0` schemas may be copied one-way into this
 `AGPL-3.0-only` repository; **no code or modifications from `wisprstudio` may
 ever be copied back into `TheHalfMoon/Wispral`**.
