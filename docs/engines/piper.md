# Piper TTS (`piper`)

Fast local ONNX CPU text-to-speech engine (`MIT` runtime + `MIT` voice catalog `rhasspy/piper-voices`).

## License & Commercial Use

- **Weights**: `rhasspy/piper-voices` (`MIT`, commercial use permitted)
- **Sample rate**: `22050 Hz`
- **Hardware**: CPU and CUDA (`onnxruntime`)

## Installation

```bash
pip install piper-tts
```

Pre-stage voice weights from the Model Catalogue (`rhasspy/piper-voices`) for offline synthesis.
