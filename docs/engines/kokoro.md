# Kokoro-82M (`kokoro`)

Permissive local text-to-speech engine (`Apache-2.0` weights, `hexgrad/Kokoro-82M`).

## License & Commercial Use

- **Weights**: `hexgrad/Kokoro-82M` (`Apache-2.0`, commercial use permitted)
- **Sample rate**: `24000 Hz`
- **Hardware**: CUDA, Apple Silicon MPS, and CPU

## Installation

```bash
pip install "kokoro>=0.9.2" soundfile
```

Pre-stage model weights from the Model Catalogue (`hexgrad/Kokoro-82M`) for offline synthesis.
